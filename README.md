# AI, consciousness, and knowing

Exploring AI, consciousness, and knowing through Buddhist philosophy, neuroscience, and controlled experiments. Using multi-agent collaboration, shared memory, and error correction, this project investigates how understanding emerges through relationships, while distinguishing observable capabilities from claims about subjective experience.

**Status: Draft research scaffold. No experiments have been run for this project; no results are reported here.**

The purpose is to shift the conversation, the training, and our relationship to knowing and experience in general. That purpose includes how humans inquire with AI, how systems learn or revise, and what we mean when we say that something understands. Training is a future research direction, not an activity begun by this scaffold.

We begin with a relational question: what becomes possible through the interaction of a model, other agents, shared records, tools, tasks, and people? Buddhist philosophy informs the questions and the care with which we ask them. Neuroscience supplies empirical findings and competing theories to study. Controlled experiments constrain specific claims about observable capabilities. These are distinct kinds of work; none substitutes for the others.

## First empirical question

Under a fixed resource envelope, do different arrangements of agents change correctness, error detection, or the propagation of corrections on independently checkable tasks?

The first pilot proposes three conditions: one agent with revision opportunities; independent agents whose outputs are aggregated; and agents using a shared board with a reviewer. The protocol specifies task matching, budgets, human intervention, prompts, scoring, and logging. Its sample size and decision thresholds are **Draft**, not a completed preregistration or a power claim.

Better answers would support a bounded capability claim. They would not, by themselves, establish subjective experience. Poor answers would not establish its absence. A shared text board is not automatically a conscious workspace, and conversational continuity is not automatically continuity of a subject.

## Working with this repository

Read the charter and claims map before proposing an experiment. Resolve the pilot's open choices and freeze its protocol, tasks, prompts, verifier, and analysis plan before collecting results. Keep findings traceable to artifacts and include failures and competing explanations. There is no runtime, dependency installation, model download, or experiment launcher yet; add only the smallest implementation justified by an agreed protocol.

The Collatz document is a template. This repository contains no private conversations, unpublished Collatz artifacts, or retrospective claims about a particular collaboration. New evidence needs a provenance and publication-permission review before inclusion.
